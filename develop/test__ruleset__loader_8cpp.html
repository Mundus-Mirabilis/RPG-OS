Detailed Description

Tests for the ruleset loader and model (rpg_os::RulesetLoader, rpg_os::Ruleset).

Verifies parsing of every schema section, the strict validation rules (duplicate ids, unknown stat references, derived-stat cycles, missing required fields such as licence), and the error reporting contract — a malformed ruleset must fail load with a descriptive std::invalid_argument rather than load a half-broken model.
