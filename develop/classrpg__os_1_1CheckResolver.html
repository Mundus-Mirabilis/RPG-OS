Resolves checkTypeId from ruleset for actor (and optional target). Throws std::invalid_argument for an unknown check type.

Why throw on an unknown name?
An unknown check type is a ruleset/authoring bug (a typo in a ruleset or a caller asking for a check the loaded system does not define). Failing fast with the offending name beats silently returning a "default" check that would resolve against the wrong mechanism.
