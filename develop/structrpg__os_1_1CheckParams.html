Detailed Description

Per-call inputs shared by both modes.

Why separate per-call inputs from the config?
The config says how a check is resolved (which mechanism, which stats); this struct carries the values that change per invocation — the difficulty imposed by the situation, and situational modifiers. Keeping them apart means the config can be built once and reused across many checks with different difficulties.
