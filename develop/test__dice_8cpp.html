Detailed Description

Tests for the shared dice engine (rpg_os::DiceExpression, rpg_os::DefaultRandom).

Pins expression parsing (groups, constants, signs, bare d20), rolling via scripted RNGs, the malformed-input error contract, and the RNG seeding contract: a fixed seed is deterministic, while unseeded instances draw from genuine entropy. These tests are the reason scripted-RNG usage stays exact in the rest of the suite.
