Detailed Description

Tests for the shared dice engine (rpg_os::DiceExpression, rpg_os::DefaultRandom).

Pins expression parsing (groups, constants, signs, bare d20), rolling via scripted RNGs, the user-defined literal forms — the "2d6+4"_dice suffix for arbitrary sizes and the 2_d6 / 1_d20 die-size suffixes with arithmetic (2_d6+2) — the malformed-input error contract, and the RNG seeding contract: a fixed seed is deterministic, while unseeded instances draw easily available entropy. These tests are the reason scripted-RNG usage stays exact in the rest of the suite.
