Detailed Description

An amount of money, always stored in the currency's base units.

Why store base units instead of a coin map?
A coin map makes arithmetic awkward (how do you add two bags?). A single base-unit integer keeps + - * and comparison trivial and exact, and the coinage is only consulted when you want a human-readable breakdown (in or fromCoins). This is the same "store the canonical value, render it on demand" choice the engine makes for stats.
