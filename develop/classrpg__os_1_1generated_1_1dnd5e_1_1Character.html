Detailed Description

Strongly typed character for the Dungeons & Dragons 5th Edition (SRD 5.2.1) ruleset. Attributes and skills are named members; derived stats are named getters with compiled formulas; checks are named methods over the shared templates. The data database is still read from the ruleset JSON.
