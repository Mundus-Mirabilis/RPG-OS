Detailed Description

Tests for the universal AST formula evaluator (rpg_os::Expression).

Covers parsing (precedence, associativity, parens), evaluation against a scripted context, the full function set, and the error paths (unresolved identifiers, division by zero, malformed input). These tests pin the restricted grammar that the code generator must also translate to C++.
