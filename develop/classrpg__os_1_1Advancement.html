Detailed Description

Experience / advancement bookkeeping for a sheet. XP is a running total; level is derived from it via the ruleset's xp_to_level cost table by the engine (the table's keys are XP thresholds, its values are levels). ap is The Dark Eye's spendable Adventure Points. Which fields a ruleset uses depends on its configuration; unused fields stay at their defaults.
