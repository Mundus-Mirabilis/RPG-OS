Detailed Description

The fully loaded model of one ruleset.

Why a plain data class instead of hidden state?
A Ruleset is a pure value: everything the engine or the code generator needs is publicly readable. Making it a plain aggregate avoids an accessor layer that would add nothing, and lets the universal engine, the loader, and the code generator share it without ceremony.
Lookup methods return raw pointers instead of optional/iterators
The lookup set is small and linear scans are fine at load/validation time; returning nullptr for "absent" keeps call sites terse and lets the engine distinguish "known, value 0" from "unknown".
