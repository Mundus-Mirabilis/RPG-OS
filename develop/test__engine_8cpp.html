Detailed Description

Integration tests for the universal engine facade (rpg_os::RulesetEngine).

Exercises the full public API end to end: loading, entity/creature creation with variance, stat calculation, named and skill checks, the JSON-driven damage/event pipeline, and listener registration. Scripted RNGs keep deterministic outcomes, so a regression in the event pipeline or the facade wiring shows up as a hard failure.
