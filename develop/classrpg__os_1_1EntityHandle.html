Detailed Description

A non-owning, stable reference to a live DynamicEntity.

A handle is created by an EntityRegistry (or a GameSession) and can be copied freely. It never owns the entity, so it never has to delete anything; it only records the entity's EntityId and a std::weak_ptr used to check liveness and to obtain a pointer when the entity is alive.

Why store the id and a weak pointer?
The id answers "which entity is this" and stays valid forever; the weak pointer answers "is it still alive / give me access". Keeping both means a dead entity can still be identified in a log or an event payload even though it can no longer be dereferenced.
