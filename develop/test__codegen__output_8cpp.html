Detailed Description

Tests for the generated "specific mode" headers in generated/.

These headers are produced by codegen/rpg_os_codegen.py from the rulesets. They must compile, expose named members/methods, still load the JSON at runtime (data database), and produce results IDENTICAL to the universal engine for the same scenario — the parity guarantee that motivates the whole dual-mode architecture. Any drift between the code generator and the universal engine fails here.
