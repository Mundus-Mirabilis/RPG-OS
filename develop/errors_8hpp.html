Detailed Description

Bookkeeping error codes.

The bookkeeping layer (inventory, equipment, currency, advancement, ...) reports expected failures — "not enough money", "slot occupied", "item not owned" — as typed error codes carried in a std::expected rather than as exceptions. Programmer errors (a malformed ruleset, an unknown id passed where one must exist) still throw std::invalid_argument; these codes are for the everyday state-machine outcomes an application has to handle and display.
