Detailed Description

Shared event system for reactive rules.

Many tabletop rules are reactive: "when damage is taken, make a wound check", "at the start of your turn, tick condition durations". The event system turns those English phrases into a small observer pattern shared by both modes:

  • the universal engine registers its JSON-driven rule triggers (EventTriggerDef, see ruleset_loader.hpp) against the bus and fires them from the damage / turn pipeline;
  • specific-mode and application code register plain callbacks for the same EventType values.
Why this design?
Keeping the event types and bus in rpg_os::common (rather than inside the universal mode) is what lets both modes react to the same events without either depending on the other. The payload is a free-form Json bag on purpose: rule effects are JSON-driven and need exactly the fields their ruleset declares, so a fixed struct would either be too narrow (rules cannot read custom fields) or too wide (everyone pays for fields they do not use). The typed getters on EventData keep the common cases ergonomic while the raw EventData::payload stays available for rules that need something bespoke.
