Detailed Description

Tests that load the real shipped rulesets (the rulesets/ JSON files).

Validates the committed data against the source documents they encode and asserts exact counts (creatures, spells, conditions, poisons, diseases) so a botched extraction that silently drops entries is caught. Because these tests read the actual rulesets, they also serve as the living acceptance check that the schema and the data stay in sync.
